# NEXUS 賽局研究所 · Worlds 2026

一個以台灣運彩英雄聯盟玩法為範圍的本機賽事研究網頁，結合可解釋的專業模型與獨立的歷史玄學觀察。深色電競風格、繁體中文介面，支援手機、平板與桌面。

**目前是可操作的情境研究工具。對戰、評分與賠率皆為示範；未串接即時盤口、官方抽籤／賽程或真人分析師預測。**

## 本機啟動

需求：Node.js 20 或以上。不需安裝套件、帳號或 API Key。

```sh
npm start
```

開啟 [http://127.0.0.1:4196/](http://127.0.0.1:4196/)。伺服器只監聽本機，不啟用公開網站部署。

如連接埠被占用，可在 PowerShell 設定：

```powershell
$env:PORT = '4197'
npm start
```

## 操作流程

1. 在「賽事雷達」篩選階段或搜尋隊伍，選擇示範對戰；也可新增／編輯自訂對戰，選擇 BO1、BO3 或 BO5。
2. 在「專業分析」調整五項相對評分與分析流派；查看系列賽模型值、盤口損益平衡機率與去水比較。
3. 在玩法選單切換不讓分、第一局不讓分、總局數讓分／大小、正確比數及第一局首殺／首龍／首塔／首巴龍。個別賽事是否開賣須自行核對官方賽事表。
4. 在「玄學觀察」讀歷史故事與限制，勾選希望保存的敘事；玄學不計入專業模型。
5. 在「分析筆記」輸入原作者、來源連結與理由，整理真人分析師的觀點。
6. 選擇玩法、方向與情境賠率，按「加入我的觀察」。同場保留一筆，重新加入會更新該場方向；這不會送出實際投注。
7. 在「我的觀察」匯出／匯入 JSON 備份。匯入採合併，不覆寫既有觀察與筆記；檔案上限 500 KB、自訂對戰上限 30 場、觀察上限 100 筆。

儲存範圍：對戰設定、分析筆記與觀察紀錄存在此網址的 `localStorage`。評分滑桿、盤口編輯、流派與篩選為本次頁面的情境設定，重新整理後重設；加入觀察時會保存選項當時的模型值與賠率。清除瀏覽器資料、切換瀏覽器或連接埠不會自動保留紀錄。

## 分析方法與限制

- 五項評分為近期狀態、對線、物件控制、版本適應、系列賽經驗。評分 0–100，50 為兩隊均衡；這不是實測戰績或勝率。
- 流派權重決定加權評分 `s`，單局參數 `p = 1 / (1 + exp(-(s - 50) / 24))`，限制在 0.1–0.9。
- 在每局獨立且 `p` 固定的假設下，枚舉合法終局比分，推算系列賽勝負、總局數、讓局與正確比數。
- BO1 隱藏總局數讓分／大小與正確比數；BO3 支援 2.5 局大小，BO5 支援 3.5／4.5 局大小。讓局固定為左隊 −1.5／右隊 +1.5。
- 首殺、首龍、首塔與首巴龍欠缺獨立事件資料，因此僅提供方向紀錄，不輸出機率。
- 隱含機率為 `1 / odds`，去水機率為各選項隱含機率除以總和。比較必須使用同一市場的完整互斥選項；模型與去水差值不代表有利可圖。
- 模型未回測、未校準，未納入選邊、BP、陣容異動與局間相關性。玄學只有歷史敘事與反例，沒有命中率或統計推論。

未提供冠軍盤（缺少全體隊伍的可靠機率與完整盤口）、實際投注、金流或同場過關。

## 規劃與結構

第一版交付範圍：雙軌分析 → 玩法對照 → 收藏筆記 → 本機備份。未來若接入真實資料，應先取得允許使用的來源，加入盤口時間戳、可投注狀態、缺漏提示及模型校準，再評估回測，不將示範數字直接改名為真實預測。

```text
index.html          頁面入口
app.mjs             畫面、事件、來源筆記、本機觀察與備份
data.mjs            示範對戰、官方連結、歷史案例、分析流派
model.mjs           系列賽分布、玩法結算、盤口與輸入驗證
styles.css          響應式介面與互動狀態
tokens.css          共用顏色
server.mjs          僅監聽 loopback 的靜態伺服器
tests/              Node 內建測試
assets/             自含主視覺，無第三方字型或 CDN
design/             視覺稿與素材生成說明
```
