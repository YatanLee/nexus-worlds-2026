# NEXUS 視覺規格與素材

本次採用內建 Image Gen 產生視覺概念與原創主視覺，未使用 API Key。

- `overview-concept.png`：首頁的主要視覺規格。
- `detail-concept.png`：分析工具、滑桿、盤口比較與手機資訊層級參考。
- `../assets/worlds-hero.webp`：從主視覺方向另行生成的獨立素材，非截圖裁切。原始影像轉為 WebP 以減少載入量。

設計系統：背景 `#0b101b`、面板 `#111c29`、文字 `#edf1fa`、邊框 `#243044`、專業分析 `#c5f56b`、玄學 `#b7a6f7`。面板圓角 12px，控制項 8px，間距以 8／12／16／24／32px 為主。使用裝置可用的中英文字型，無外部字型請求。桌面側欄在手機改為底部四項導覽；保留語意標題、鍵盤焦點、原生表單與減少動畫偏好。

視覺稿的刻意修正：不呈現虛構日期、隊伍官方 Logo、虛構分析師數據或玄學機率。環形圖表達兩種視角，不顯示百分比。細節稿生成的額外頁首、通知、人物插圖與錯誤日期未採用；沿用主要規格的側欄、獎盃及資料邊界。

生成提示摘要（完整意圖）：

1. `ui-mockup`：完整繁中 NEXUS 世界賽研究儀表板；深海軍藍背景、萊姆綠／薰衣草紫、左側導覽、Worlds 2026 獎盃橫幅、三場情境賽事列、專業／玄學雙軌面板與觀察清單。介面文字與控制項由程式碼實作。
2. `standalone background asset`：以主稿為參考，生成寬幅原創銀色切面獎盃、右側綠色能量圓弧、岩石與霧氣；左側黑綠留白供 HTML 文字使用；不含文字、品牌、按鈕或 UI。
3. `ui-mockup`：同一配色的 C9／KC 情境分析詳情與手機參考；專業／玄學／筆記頁籤、五項評分滑桿、盤口機率比較、歷史敘事與反例。
